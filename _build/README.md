# How this site is built

This folder is not part of the public website. GitHub Pages ignores folders that start with an underscore.

Most pages on ummahbrief.com are generated by two Python scripts in this folder. If you only need to change a link, a price or a switch, you can edit the finished page directly (see "Quick edits"). If you want to change the design or the wording across pages, change the script and run it again.

## What generates what

| Page | Made by | Edit by hand? |
|---|---|---|
| `/index.html` (homepage) | `gen.py` | Yes for quick edits |
| `/briefs/riba-exit/` | `gen.py` | Yes for quick edits |
| `/guide/` and `/guide/thanks/` | `gen.py` | Yes |
| `/riba-check/` | `gen.py` | Yes |
| `/ledger/` | `gen.py` | Yes |
| `/mediation/` | `gen.py` | Yes |
| `/privacy/` and `/terms/` | `gen.py` | Yes |
| `/guide/where-did-it-go.pdf` | `guide_pdf.py` | No. Regenerate it |
| `/rizq-code/index.html` (sales page) | Not generated. Edited by hand | Always |

`gen.py` holds the shared design (colours, fonts, header, footer) in one place, so a change there reaches every generated page.

## Running the scripts

From the top of the repository:

```
python3 _build/gen.py .
python3 _build/guide_pdf.py .
```

- `gen.py` needs only Python 3.
- `guide_pdf.py` also needs Playwright and Google Chrome, because it prints a web page to PDF: `pip install playwright`. It expects Chrome at `/usr/bin/google-chrome`; change `executable_path` in the script if yours is elsewhere.
- After running `guide_pdf.py`, refresh the cover image: `pdftoppm -r 75 -f 1 -l 1 -png guide/where-did-it-go.pdf /tmp/c && mv /tmp/c-1.png guide/cover.png`.

Running `gen.py` overwrites the generated pages, so any quick edit made by hand must also be made in `gen.py` or it will be lost.

## Quick edits (no scripts needed)

| To change | File | What to edit |
|---|---|---|
| Where "free guide" buttons go | `index.html` | `var GUIDE_URL` near the bottom |
| Put the Riba Exit Brief on sale (homepage) | `index.html` | `var BRIEF_ON_SALE = true` near the bottom |
| Put the Riba Exit Brief on sale (its page) | `briefs/riba-exit/index.html` | Paste the Systeme checkout link into `var CHECKOUT_URL` near the bottom |
| The Rizq Code checkout link | `rizq-code/index.html` | Search for `checkout.ummahbrief.com` |
| Where a form sends signups | Any page | The form's `action=` address |
| The label a signup arrives with | Any page | The hidden `source` field inside the form |

## Adding a new Brief page

1. In `gen.py`, the `BRIEFS` list holds each Brief's number, title, promise and colour.
2. Copy the "RIBA EXIT BRIEF" block, change the content, and write it to `briefs/<name>/index.html`.
3. In the homepage block, turn that Brief's sleeve from a waiting-list link into a link to its page.
4. Run `gen.py`.

## Forms

All forms currently post to Formspree. Signups are told apart by their `source` label:
"homepage newsletter", "Free guide: Where did it go?", "Riba Check", "Ledger story", and the Brief waiting lists.
The mediation form uses its own Formspree form.
